# Let's Art (렛츠아트) — 세계 명화 갤러리 & 불후의 고전 문학 아카이브

**렛츠아트(Let's Art)**는 세계 85대 미술관(메트로폴리탄 미술관, 루브르, 오르세, 시카고 미술관, MoMA 등)의 오픈 액세스 퍼블릭 도메인(CC0) 데이터를 기반으로 한 **세계 18,540점 명화 인터랙티브 가상 갤러리** 및 **6,240편 불후의 고전 문학 아카이브** 서비스입니다.

## 🏛️ 주요 기능
1. **세계 명화 가상 갤러리**:
   - 르네상스, 바로크, 낭만주의, 인상주의, 후기 인상주의, 입체파 등 사조별 대표작 고해상도 감상.
   - 캔버스 3D 틸트 효과 및 원목 액자 시뮬레이터.
   - 대표 색채 5대 팔레트 추출 및 큐레이터 심층 도상학 해설.
2. **세계 대문호 고전 아카이브**:
   - 셰익스피어, 괴테, 단테, 톨스토이 등 시대를 초월한 명작의 시대적 배경, 시놉시스, 인물 관계도, 불후의 명문장 수록.
3. **연합 URN 표준**:
   - `urn:art:work:painting:{work_id}`
   - `urn:art:literature:{lit_id}`
   - 렛츠피플(`urn:people:person:historical:*`) 및 컬처플로우(`urn:culture:*`)와 양방향 결합.
4. **24/7 무인 자동 증분 수집**:
   - GitHub Actions 크론(`0 21 * * *`)을 통한 매일 신규 오픈 액세스 명화 및 고전 텍스트 인덱싱.
